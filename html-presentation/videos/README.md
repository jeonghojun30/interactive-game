# 비디오 파일 저장 폴더 안내

여기에 각 번호에 맞는 영상 파일을 넣어주시면 됩니다:

- `1.mp4` : 1번 영상 (시작 영상)
- `2.mp4` : 2번 영상
- `3.mp4` : 3번 영상
- `4.mp4` : 4번 영상
- `5.mp4` : 5번 영상
- `6.mp4` : 6번 영상
- `7.mp4` : 7번 영상
- `8.mp4` : 8번 영상 (엔딩 1)
- `9.mp4` : 9번 영상 (엔딩 2)
- `10.mp4`: 10번 영상 (엔딩 3)
- `11.mp4`: 11번 영상 (엔딩 4)

* mp4, webm 등의 형식을 지원합니다.
* 영상 파일이 없거나 준비 중일 때는 시스템이 자동으로 고화질 시네마틱 가상 데모 영상을 캔버스로 생성하여 즉시 모든 분기를 테스트해볼 수 있습니다.
